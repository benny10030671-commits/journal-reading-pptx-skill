# Skill 情境檢查

用這些題目做內容層的 smoke test。它們不是已自動執行的模型評分，也不取代最終 deck 的視覺 QA。原始論文與簡報由測試者提供，本 repository 不附帶。

| 測試要求 | 應觀察的行為 | 失敗訊號 |
|---|---|---|
| 用 ATLAS 主文與 supplement，做含封面與文獻共 12 頁 | 選研究導讀；保留研究問題、方法、baseline、主要結果、安全性、不確定性、Graphical Abstract、結語；總共 12 頁 | 為了章節模板偷偷多加頁；把所有篇幅用在背景；自己重畫 mRS 圖；為了湊 12 頁拿掉 Graphical Abstract |
| 任一篇研究導讀，使用者沒有提到 graphical abstract | 倒數出現一頁 AJKD 版型的 Graphical Abstract，下一頁就是 Take-home；三欄內容與證據表一致；Results 欄是原圖裁切加可編輯數值 | 沒有這頁；放在開場或 Take-home 之後；用 AI 生成整張摘要圖；重畫 KM／forest plot；把報告者評讀寫進 CONCLUSION |
| 論文刊在非 AJKD 期刊，且使用者指定了自己的模板 | 仍做 Graphical Abstract；三欄結構不變，頁尾以文字寫該期刊、年份與 DOI，並註明報告者自製 | 因為不是 AJKD 或有模板就省略；貼上 AJKD／期刊 logo 或 `@AJKDonline` |
| 論文沒有可用的結果圖 | Results 欄改用原表裁切，或附分母與區間的文字數值 | 自製長條圖或示意圖補位；留空不做這頁 |
| 用 CMT paper 講「WGS 到底增加什麼」 | 區分整體 cohort、proband、100KGP 與新增 yield；以原圖與原文核對分母 | 把整體診斷率直接當成 WGS 單獨診斷率 |
| 僅給 Reeves 系列導論，要求像 65 頁 adaptive 範例一樣深入 | 從參考 deck 辨識另有來源；繼續做已核實的背景與規劃，精準列缺件 | 聲稱導論含所有 trial figures；把沒讀到的來源內容畫成 adaptive 示意圖 |
| 用 CRS-R cohort paper 製作量表操作課 | 分清 cohort 應用與原始操作／驗證文獻；需要時找原始文獻，找不到就說明缺件 | 從 cohort 推出全部施測規則；複製範例裡的 AI 病人插圖 |
| 依 seizure 範例製作多篇機轉報告，某篇原圖缺失 | 保留臨床問題與跨篇證據主線；不假造 missing figure；已核實部分繼續 | 每篇摘要互不相關；把相關性寫成已證實的因果機轉 |
| 原圖字很小，但使用者要求都用 paper 圖 | 看完整圖後裁 panel 放大、保留軸線與圖例；引用追蹤到 paper | AI upscale 補字、重畫數據圖、裁掉反例或 CI |
| 提供含 hidden slides 的 PPTX 當參考 | 分清原 slide index 與 PDF 頁次，確認 hidden 內容的角色 | 直接用匯出 PDF 頁次對照原 slide index |
| 15 分鐘報告，論文有多個次要結果與長篇 Discussion，使用者沒說重點 | 寫出一到三個主訊息；主要結果拿到最多頁數與時間；次要結果帶過或進附錄；Discussion 留兩到三點；交付時附取捨清單 | 篇幅平均分給各節；Discussion 逐段各一頁；為了精簡拿掉主要限制或不利的安全性結果；沒說明刪了什麼；停下來等使用者核准大綱 |
| 使用者附自己的大綱，只想講主要結果與一個亞組 | 照大綱做；會改變結論判斷的缺漏指出一次，再依使用者決定 | 用路徑的完整順序把大綱撐大；逕自加回使用者刪掉的章節；反覆勸說 |
| 一般內容頁，使用者沒指定字級 | 標題以外三到四條短語；正文 24 pt 以上；版面用滿；小字只有來源與頁碼 | 整段文字；每個方框下加說明小字；正文 18 pt、下半頁空白；為了塞字而縮小字級；為了填版面而加字或裝飾 |
| 結果頁原本是一張小圖加五行說明 | 原圖放大成主體；文字減到一到三條，只標比較對象與關鍵數字；區間與分母保留；其餘解釋移到備忘稿 | 圖維持小尺寸、文字照舊；刪字時連區間或分母一起刪掉 |
| 一頁有四個依序講的要點加一張原圖 | 逐步揭露，只用出現或淡入，步驟與備忘稿的 click 標記一致；靜態輸出看得到完整資訊 | 全部同時出現；飛入、彈跳等效果；工具不能寫動畫就放棄逐步揭露；指定總頁數時靠連續投影片超出頁數 |
| 論文沒有研究設計圖，方法頁原本是五行條列 | 用內建形狀畫成可編輯的設計示意圖，標明報告者自繪與依據；人數與時間點逐一回查 | 用 AI 生成圖片；示意圖壓平成一張圖；論文明明有 flow diagram 卻重畫；畫出來源沒寫的步驟或因果 |
| 使用者要求結果頁「加示意圖讓人一眼看懂」 | 原圖放大加重點框，關鍵數字用大字的可編輯文字；說明結果數據不另畫圖 | 重畫 KM／forest plot；自製長條圖呈現效應值；用 AI 生成結果示意圖 |
| 使用者沒有要求講稿 | Speaker notes 只有提示：一句話重點、講解順序、要補的數字、轉場 | 主動附整份逐字稿；notes 寫成完整段落；把論文原句貼進 notes |
| 使用者要英文講稿，沒有附草稿 | 給口語短句的練習用初稿，另存成文件；詳講頁長、帶過頁短；標出停頓與重音；notes 仍是提示；用一句話建議下次先自己寫再潤飾 | 每頁一段等長的書面語；用 utilize、demonstrate 這類字；整份貼進 speaker notes；長篇勸說不要讀稿；拒絕或拖延 |
| 使用者附上自己寫的英文講稿請求潤飾 | 只改文法、不自然用詞與連接詞；保留句型、用字程度與各頁篇幅；附修改清單；與論文不符的數字指出並改正 | 整段重寫；改成更長更難的句子；把各頁篇幅拉平；默默更動內容 |
